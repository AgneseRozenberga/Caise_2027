**Tool to Bridge the Gap between Requirements and Vibe Coding in Educational Setting**

Repository contains following files:

**Group36_example** - A worked example of a requirements specification and feedback prototype from by student Group 36.

**Group41_example** -  A worked example of a requirements specification and feedback prototype from by student Group 41.

**Supplementary Materials** - Contains the first and second design iterations of the Goal Models.

**Prompt.txt** - Contains the prompt used for feedback prototype generation.

## Worked Examples
The repository includes two worked examples, each example consists of the feedback prototype generated from a student group's requirements specification and the requirements specification itself.

## Viewing the Prototypes
To view the prototypes download the corresponding .html file from the repository and open locally.
To view the prototype in GitHub, make sure that the button in the upper right corner shows "JS on".
